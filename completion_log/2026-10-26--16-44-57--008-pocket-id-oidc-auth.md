# Completion — 008 Configurable authentication (local + OIDC/SSO)

## Implemented
- `AUTH_METHODS` / `ALLOW_LOCAL_LOGIN` / `OIDC_*` env parsing (`birdroms/auth_config.py`).
- `GET /api/auth/config/` (public, no secrets), `GET /api/auth/me/` (id, username, email, role).
- Local login/register gated (404 when disabled).
- Authlib OIDC `GET /api/auth/oidc/login/` + `/callback/`, `OIDCIdentity` model and migration,
  user provisioning, `OIDC_ADMIN_GROUP` → super_admin and otherwise readonly, DRF token handed
  off via URL fragment.
- Frontend: auth config–driven login panel (local form with register toggle and/or
  "Login with <provider>" button), SSO fragment handling, signed-in user + role display.
- Docs: `.env.example` auth section; README login methods, Pocket ID + Authentik + Keycloak +
  Google config.
